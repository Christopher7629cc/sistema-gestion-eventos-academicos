# Sistema de Gestión de Eventos Académicos

Proyecto semestral – Avance #1.

## Caso
Sistema para registrar y administrar eventos académicos, participantes,
inscripciones, horarios, espacios, categorías, reportes y notificaciones.

## Estructura
- `src/main/java`: código fuente Java.
- `src/main/resources`: recursos.
- `docs/uml`: diagrama de clases UML.
- `docs/Avance_1_Eventos_Academicos.docx`: documentación del primer avance.

## Clases
Usuario, Participante, Organizador, Evento, Inscripcion, Horario,
Espacio, Categoria, Reporte y Notificacion.
